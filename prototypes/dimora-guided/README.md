Demo lineare indipendente: Agenzia → Home → Amministratore → Home, introduzione e 12 passaggi. Solo dati fittizi in memoria; refresh e Ricomincia azzerano la sessione. Nessuna API reale.

Aprire dist/index.html oppure servire dist con un server statico. Test: `node test.cjs` (12 controlli). La demo libera preesistente resta separata e invariata.
